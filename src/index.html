Таймлайн матча

Метки: спавн кораблей (строки Spawn в combat.log), убийство врага, смерть союзника (кто кого — в подсказке). Зажмите на дорожке начало и конец интервала и отпустите — выбранный отрезок увеличится (масштаб по времени). Ползунки можно тянуть отдельно. «Сбросить» — весь матч. Графики и таблица используют фильтр по времени.

Детализация урона

Сводная таблица урона по дефолтным наборам модификаторов для выбранного игрока (источник). В колонке «Модификаторы»: nil — не учитывать, true — должен присутствовать, false — должен отсутствовать.
